GPU gas spike

The GPU gas plan's spikes: a WebGPU grid sort and SPH pressure, run in the simulation worker, timed per substep. Keep the screen on and the tab in front; it takes a minute or two.

Spike 2 runs each cluster in one work-group, every substep of a batch in one dispatch, with barriers between the stages (clear, count, running total, scatter, density, force, substep length); clusters run side by side. Spike 1 (?spike=1) runs each substep as 7 dispatches. Times are wall clock round a batch of substeps and a small read-back, as the game would run them.

GPU gas spike

Phase 0 of the GPU gas plan: a WebGPU grid sort and SPH pressure, run in the simulation worker, timed per substep. Keep the screen on and the tab in front; it takes about a minute.

Parcelsµs / substepsortdensity + forceµs per 10kneighbours

Each substep is one submit's share of 7 dispatches (clear, count, two scans, scatter, density, force). Times are wall clock round a batch of substeps and a 16-byte read-back, as the game would run them. "Sort" and "density + force" are each run alone.
